# 项目长期记忆 — 另类数据挖掘之退市风险

## 项目概述
基于A股退市风险公告文本数据的另类数据挖掘项目，核心目标：
1. 识别退市风险公司（区分退市风险警示 vs 退市实施）
2. 挖掘摘帽机会（撤销退市风险警示的公司）
3. 聚焦科创板、北交所、创业板三大板块

## 数据资产
- **退市风险公告**：另类数据挖掘之退市风险.xlsx（5个Sheet，202家公司，672条公告）
- **简称变更**：简称变更.xlsx（7373条，含ST摘帽/加星记录）
- **股票画像**：df_all_type.csv / 2026年个股画像动态标签.txt（5495条，含行业/标签/实控人等27列）
- **估值数据**：2026年PE市盈率PB市净率ROE投资风格.txt（5517条）
- **行情数据**：dataprices_20260515.csv（5495条）
- **异常波动**：2027年个股异常波动标签画像.txt（1747条，含游资偏好度）
- **短线指南**：2026年短线动态操作指南.txt（2878条）

## 核心方法论
- 风险状态5级分类：摘帽成功/摘帽申请中/退市风险实施中/风险提示中/其他
- 机会评分模型（0-100）：摘帽次数(45)+风险低频(15)+实施低频(10)+PB正(10)+国企(10)+有实控人(10)

## 关键发现（2026-05-15数据）
- 创业板摘帽率最高(90.9%)，无退市风险实施中公司
- 北交所0摘帽，风险密度最高
- 科创板5只摘帽/申请中，7只高危

## 技术栈偏好
- 可视化：ECharts > Highcharts > Chart.js
- 数据处理：Python(pandas) + R(dplyr/tidyr)
- 输出格式：HTML网页 + R代码 + Python代码
- 中国股市配色：涨=红，跌=绿
