🧮 极差模型算法原理
Range Spread Model — 核心公式与逻辑
1. 累计收益率
CRi(t) = Pi(t) / Pi(0)

2. 滚动Z-Score标准化
Zi(t) = [CRi(t) - μi(t)] / σi(t)
其中 μi(t) = mean(CRi(t-W:t)), σi(t) = std(CRi(t-W:t)), W=60

3. 极差 (Range Spread)
RS(t) = Zhigh(t) - Zlow(t)

4. 布林带预警
Upper(t) = μRS(t) + 2·σRS(t)
Lower(t) = μRS(t) - 2·σRS(t)

5. 交易信号
Signal = +1 当 RS(t) > Upper(t) → 高位股过热，低位股超跌
Signal = -1 当 RS(t) < Lower(t) → 低位股走强，高位股回调

📐 均值回归半衰期

对极差偏差序列 ε(t) = RS(t) - μRS(t) 拟合AR(1)模型：
ε(t) = φ·ε(t-1) + ξ(t)

半衰期: t1/2 = -ln(2) / ln(φ)

含义：极差偏离均值后，回归至一半所需的天数。
半衰期越短，均值回归速度越快，配对交易机会越多。

🔬 极差的扩展应用

1. 配对交易 (Pairs Trading) — 当极差偏离阈值时，做空高位股、做多低位股，等待均值回归获利

2. 行业轮动监测 — 追踪科技/消费、成长/价值板块间的极差变化，识别风格切换节点

3. 风险预警系统 — 极差持续扩大往往预示市场结构性风险积聚

4. 情绪指标构建 — 极差反映市场极端分化的程度，可作为贪婪/恐惧指标

5. 因子暴露分析 — 解构极差中各风险因子的贡献度
