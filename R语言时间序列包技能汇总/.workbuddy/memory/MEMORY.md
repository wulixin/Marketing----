# Memory - R时间序列包技能汇总项目

## 项目概况
- 路径: `/Users/wulixin/Documents/GitHub/Marketing----/R语言时间序列包技能汇总/`
- 主文件:
  - `index.html` - R时间序列包技能汇总，基于CRAN Task View: Time Series Analysis
  - `finance.html` - R实证金融包技能汇总，基于CRAN Task View: Empirical Finance
- 数据来源:
  - https://mirrors.tuna.tsinghua.edu.cn/CRAN/web/views/TimeSeries.html

## 技术栈
- D3.js v7 (CDN) - 力导向网络图
- 原生JS - 交互逻辑、中英文切换
- Canvas API - 背景粒子动画
- 纯CSS - 深色主题、渐变效果

## 通用设计模板
- D3力导向网络图谱 + 技能卡片 + 包列表三视图
- 中英文双语切换
- 全局搜索过滤
- 深色主题 + 背景粒子动画
- 点击分类弹窗显示完整包列表
- 响应式布局
- 可复用于任意CRAN Task View
